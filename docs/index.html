Guild Wars 2 ArcDPS Plugin

GW2 ArcDPS 繁體中文 UI

下載 arcdps_tchineseui.dll，讓 Guild Wars 2 介面使用中文，並提供繁體中文顯示、簡體轉繁體詞彙修正，以及重啟後自動套用的設定保存。

下載最新版 查看 GitHub

主要功能

  • 提供 ArcDPS 外掛形式的中文 UI 支援。
  • 可切換中文 UI 與繁體轉換模式。
  • 記住設定，重啟遊戲後自動套用。
  • 內建簡體轉繁體詞庫與額外詞彙修正。

安裝方式

  1. 先安裝 ArcDPS。
  2. 從 Releases 下載 arcdps_tchineseui.dll。
  3. 將 DLL 放到 Guild Wars 2 目錄，與 arcdps.dll 同一層。
  4. 啟動遊戲後從 ArcDPS UI 調整外掛設定。

設定檔

外掛會將設定寫入：

addons/arcdps/arcdps_tchineseui.ini

目前保存 chinese_enabled 與 trad_mode_enabled。

下載檔案

最新版本會在 GitHub Releases 提供 DLL 與 ZIP。若只想安裝外掛，下載 arcdps_tchineseui.dll 即可。
