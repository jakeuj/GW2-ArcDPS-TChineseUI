What it changes

不只把字換掉，
也保留你的選擇。

外掛以 ArcDPS 擴充載入，將中文介面、繁體轉換和重啟後狀態串成一條可理解、可追查的流程。

In-game preview

GAME CAPTUREON VIEW

Safe installation

四步完成，載入位置以日誌為準。

常見位置是遊戲根目錄或 bin64。請以 addons/arcdps/arcdps.log 的完整路徑為準，不要兩邊各留一份。

  1. 01
    準備 ArcDPS

    先安裝 ArcDPS，完全關閉遊戲並確認 Gw2-64.exe 已結束。

  2. 02
    備份既有設定

    備份原 DLL，以及 addons/arcdps/arcdps_tchineseui.ini。

  3. 03
    放入唯一載入位置

    下載 arcdps_tchineseui.dll，依日誌路徑替換舊檔。

  4. 04
    啟用並確認

    進入 ArcDPS 擴充列表啟用 TChinese UI，勾選需要的模式。

arcdps.logHEALTHY
[trad/enable] enabled
[init/complete] ready
[language/queue] language-id=5
[language/apply] completed

Traceable by design

遇到問題，不必盲猜。

fork.5 起會以 [init/<階段>] 標示確切失敗位置。看到 [trad/<階段>] unavailable 則代表外掛已降級載入，簡體中文仍可使用。
